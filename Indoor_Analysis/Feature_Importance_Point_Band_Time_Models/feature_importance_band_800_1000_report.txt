Indoor Feature Importance within WA Point Band 800-1000
============================================================

Question: Do previously important features (bal/spec, best_event,
best_is_from, pair WA gap, from_stronger_wa, bal×best_event) make
the indoor band 800-1000 time models more accurate than the pooled band model?

Method:
  • Indoor CSVs 2024–2026 (all dates in files); no relays.
  • Events: Sprints 60/200/400; Distance 800/Mile/3000.
  • Inclusion: ≥1 result with WA in [800, 1000).
  • For each event pair (n≥20): 5-fold CV routes predictions by feature
    labels; sub-cohorts need n≥12 to fit a dedicated model,
    else fall back to the pooled band formula.
  • “Beats pooled” = CV median |error| improves by >0.01s.
  • Athlete-seasons in band: 319.
  • Evaluated pairs: 16.

Feature definitions
-------------------
  • bal_spec: balanced vs specialized (wa_spread ≥ 50)
      How to use: Compute wa_spread = max(event WA) − min(event WA) across events with a season PB. specialized if ≥ 50; else balanced.
  • best_event: Identity of best-WA event in the group
      How to use: Identify which event in the group has the athlete's highest season WA; route to the best_<event> formula.
  • best_is_from: Athlete's best-WA event is the source event
      How to use: Check whether the athlete's best-WA event equals the source (from) event. Yes → best_is_from formula; no → best_not_from.
  • pair_wa_gap_50: |WA(from)−WA(to)| ≥ 50
      How to use: Compute |WA(from) − WA(to)|. If ≥ 50, use pair_gap_ge50; else pair_gap_lt50.
  • from_stronger_wa: Source event has higher WA than target
      How to use: Compare WA(from) to WA(to). If from ≥ to, use from_stronger_wa; else from_weaker_wa.
  • bal_x_best_event: bal/spec × best_event joint route
      How to use: Need both bal/spec (wa_spread ≥ 50) and best_event. Prefer the matching cell formula when n is large enough; else fall back to best_event, then bal/spec, then pooled.
  • best_is_to: Athlete's best-WA event is the target event
  • pair_wa_gap_median: |WA(from)−WA(to)| relative to band-pair median
  • events_competed: Distinct events raced: 2 vs 3+
