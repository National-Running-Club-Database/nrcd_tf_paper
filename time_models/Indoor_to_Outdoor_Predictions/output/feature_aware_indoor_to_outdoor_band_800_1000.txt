Feature-Aware Indoor → Outdoor Time Models — WA Band 800-1000 (Width 200)
=========================================================================

Method:
  • Same indoor→outdoor pairs and feature routing as
    feature_aware_indoor_to_outdoor_findings.txt.
  • Band membership: indoor from-event season-best World Athletics score
    ∈ [800, 1000). The WA value is taken from the athlete's best
    (fastest / farthest) indoor mark in the from-event that season.
  • Pooled + feature cohort formulas; CV seed=42, folds=5; cohort n≥12;
    pair needs n≥20 after banding.

Use:
  1. Compute the athlete's indoor from-event season PB and its WA score.
  2. If that WA is in [800, 1000), use this band's formulas.
  3. Start from the pooled formula; switch to feature-cohort formulas when labeled.
  4. For pure forecasting (outdoor unknown), prefer bal_spec / best_is_from
     over from_stronger_wa / pair_wa_gap_50.

  Pooled model: linear_ols
  Formula: Outdoor 100m = 1.6188 × Indoor 60m − 0.3392
  CV median |error| (pooled routing): 0.167s
  Full-sample median |error|: 0.152s
  Ratio Outdoor 100m/Indoor 60m: median 1.566 (IQR 1.546–1.590)
  Median marks: Indoor 60m 7.14, Outdoor 100m 11.19

  Important features to know
  --------------------------
  • Recommended route: pair_wa_gap_50 (CV 0.080s, Δ +0.087s vs pooled).
  • How to determine it: If |WA(indoor from) − WA(outdoor to)| ≥ 50, use large_gap; else small_gap.
  • Other features that also beat pooled:
      - pair_wa_gap_50: CV 0.080s (Δ +0.087s) ← recommended
      - from_stronger_wa: CV 0.118s (Δ +0.049s)
      - best_is_from: CV 0.125s (Δ +0.042s)

  How pair_wa_gap_50 alters the formula:
  • Baseline (pooled): Outdoor 100m = 1.6188 × Indoor 60m − 0.3392
  • If |WA(indoor from) − WA(outdoor to)| ≥ 50, use large_gap; else small_gap.
      [large_gap] n=39: Outdoor 100m = 1.5914 × Indoor 60m  (full-sample MedAE 0.093s)
      [small_gap] n=39: Outdoor 100m = 1.6214 × Indoor 60m − 0.4900  (full-sample MedAE 0.069s)

  How from_stronger_wa alters the formula:
  • Baseline (pooled): Outdoor 100m = 1.6188 × Indoor 60m − 0.3392
  • Compare WA(indoor from) to WA(outdoor to). If from ≥ to, use from_stronger_wa; else to_stronger_wa. (Requires knowing outdoor to-event WA — validation routing.)
      [from_stronger_wa] n=57: Outdoor 100m = 1.5818 × Indoor 60m  (full-sample MedAE 0.133s)
      [to_stronger_wa] n=21: Outdoor 100m = exp(0.789 + 0.814×log(Indoor 60m))  (full-sample MedAE 0.078s)
